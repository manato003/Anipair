[Annict](https://annict.com/)の視聴記録をタップだけで付けていくためのWebアプリです。見たアニメを1タップで評価でき、その評価から好みを推定して、まだ見ていない作品を提案します。記録はすべて自分のAnnictに保存されます。

Annictの非公式の個人開発アプリで、Annictの運営とは関係がありません。

## 使い方

使い始めるのに必要なのは**Annictのアカウント**だけです。ふだんは2〜4を行き来しながら使います。

### 1. Annictでログインする

[公開版](https://anipair.com/)を開き、「Annictでログイン」を押します。これまでAnnictに付けた記録がそのまま読み込まれます。

### 2. 見た作品を評価する（評価）

<table><tr>

<td valign="top">

クールごとの人気作が1枚ずつ出てきます。下のボタンで答えると、次の作品に進みます。

- 見た作品: 「良くない」から「とても良い」までの4段階
- 見ていない作品: 「見てない」
- 気になる作品: 「見たい」

間違えたら「ひとつ戻る」で取り消せます。上の線はそのクールの人気作のうち答えた数を表します。矢印でクールをさかのぼっていくと、昔見た作品の記録がたまっていきます。

## 記録の置き場所

Anipairは利用者の記録やトークンを置く運営サーバーを持ちません。

| データ | 置き場所 |
|---|---|
| 見た・見たい・評価などの記録 | あなたのAnnict |
| 興味なし・保留・見てない・見たいのメモ・Tier表など、Annictに置けないもの | この端末（GitHubと連携すると、あなたのprivateリポジトリにも） |
| トークン・設定 | この端末だけ |

例外は、利用者が自分から送ったものだけです。問い合わせの内容と、リンクで共有したTier表（題名・段の名前・作品の並び）は、Anipairが受け取ります。

どの画面が開かれたかは、Cookieを使わない[Vercel Web Analytics](https://vercel.com/docs/analytics/privacy-policy)で集計しています。

通信先と保存するものは、すべて[プライバシーポリシー](https://anipair.com/privacy.html)に書いてあります。

## GitHub連携（任意）

連携しなくても、すべての機能を使えます。自分のGitHubのprivateリポジトリとつなぐと、Annictに置けない記録をPCとスマホで共有でき、作品ごとの記録を毎日自動でバックアップします（変更履歴つき）。連携しない場合も、設定の「ファイルに書き出す」でJSONファイルに保存できます。

<details>
<summary>連携の手順（アプリの設定にも同じ手順があります）</summary>

1. GitHubでprivateリポジトリを作成します（例: `anipair-data`）
2. [Fine-grainedトークン](https://github.com/settings/personal-access-tokens/new)を作成します。Repository accessは手順1のリポジトリだけを選び、PermissionsのContentsを「Read and write」にします
3. 設定の「GitHub連携」にリポジトリ名（`ユーザー名/anipair-data`）とトークンを入力し、「連携する」を押します

</details>

設定の「お問い合わせ」から送れます。GitHubのアカウントは要らず、送った内容は開発者だけが読みます。GitHubを使う方はこのリポジトリの[Issues](https://github.com/manato003/Anipair/issues)からも送れます（こちらは公開されます）。

## 注意

- AnnictのAPIはベータ版で、予告なく変わることがあります。変わると、動かなくなる機能が出るかもしれません
- Annictから読むのは、AnnictのAPIで公開されている情報だけです
- 表紙はShikimoriのポスターを優先し、無ければAnnictのAPIの画像（作品の公式サイトのもの）を出します。画像の権利は各権利者にあります

## 開発

Vite + React + TypeScriptの静的サイトです。サーバーで動く処理はVercelの関数（`api/`）の4つだけです（ログインの受け渡し・Shikimoriへの中継・問い合わせの受け付け・Tier表の共有のリンク）。

```
npm install
npm run dev      # http://localhost:5173
npm run lint
npm run typecheck
npm test
npm run build
```

<details>
<summary>ローカルでのログインと、自分で公開する方法</summary>

- 個人用アクセストークンで使う: ローカルでは「Annictでログイン」のボタンが出ません（ログインの関数が動かないため）。最初の画面の「開発者向け: 個人用アクセストークンで使う」を開き、Annictの[アプリケーションの設定](https://annict.com/settings/apps)で作った個人用アクセストークン（権限は「読み込み + 書き込み」）を貼ってください
- 「Annictでログイン」をローカルで試す: Annictに[アプリケーションを登録](https://annict.com/oauth/applications)し（スコープは「読み込み + 書き込み」、リダイレクトURIは`http://localhost:3000/`）、`.env.example`を見て`.env.local`に値を入れてから、`vercel dev`で起動します
- 自分で公開する: このリポジトリをフォークしてVercelにつなぎ、`.env.example`にあるログインの4つの環境変数を設定します（`ANNICT_CLIENT_SECRET`などに`VITE_`を付けないでください。付けると公開のJSに入ります）。AnnictのアプリケーションのリダイレクトURIには、公開するアドレス（末尾のスラッシュまで）を登録します。問い合わせの受け付けとUpstashの環境変数は任意で、無ければ問い合わせとTier表の共有は使えず、Shikimoriへの中継は控えなしで回数を抑えて動きます

</details>
